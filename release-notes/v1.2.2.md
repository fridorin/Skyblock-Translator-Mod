# SkyBlock Translator 1.2.2

Minecraft: **1.21.11, 26.1.2, 26.2 and 26.3**. Install the JAR and Fabric API/YACL builds matching your game. Fabric Loader 0.19.5+ is required.

## New in 1.2.2

- Fix inventory-title translation at the actual container label rendering calls, with version-specific injection checks.
- Preserve formatting/player/command placeholders when templating numbers, inherited component styles, and Unicode letters when comparing translations.
- Respect the ability-description, enchantment-description and rarity switches for standard item lore sections.
- Keep outgoing translations in order, fall back to the original message on failure, and prevent messages/translations from crossing server connections.
- Restrict the Hypixel-only option to actual Hypixel domains, and avoid translating in menus, singleplayer or background indexing when that option is enabled.
- Validate missing/invalid configuration values and language codes without overriding existing feature switches.
- Isolate language caches and reject stale API responses while switching language or clearing caches. Save config, cache and dictionary files atomically and avoid postponing cache saves indefinitely.
- Protect dictionary updates against language-switch races. Refresh derived item tables after downloads, preserve regex character classes, apply user phrase overrides and skip invalid replacement references.
- Add brief negative caching to avoid repeatedly translating unchanged text every frame.
- Make the technical filters effective and stop discarding meaningful messages merely because they contain a progress-style bracket.
- Make `/translator test` use the online path instead of a possible local dictionary hit.
- Rewrite English, Russian and French documentation for the current behavior and dependencies; fix project links, navigation and JSON examples. Add a multilingual Modrinth description and automated documentation/localization checks.
- Synchronize the public Modrinth description during release publication; report missing/insufficient credentials as a failed publishing step.

## Included from 1.2.1 — previously GitHub-only

- Fix the scoreboard startup crash on Minecraft 26.1.2, 26.2 and 26.3, including the failure reported alongside SkyHanni (#3, #4).
- Fix offline matches when formatting codes split item stats or phrases.
- Apply Shift bypass and settings changes immediately to entity names, scoreboard and Tab.
- Remove stale per-feature caches and deduplicate pending component translations.
- Improve language cache isolation, support French/other Latin-script cache entries and use locale-independent dictionary keys.
- Refresh translations after dictionary edits and reload the selected language with `/translator reload`.
- Preserve nested bypass state, retry failed cache writes and prevent malformed API keys from exhausting request permits.
- Add regression tests and per-version mixin target checks; publish separate Modrinth versions for each Minecraft target.
