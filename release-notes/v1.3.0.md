# SkyBlock Translator 1.3.0

Minecraft **1.21.11, 26.1.2, 26.2 and 26.3**. Use the matching JAR, Fabric API and YACL. Fabric Loader **0.19.5+** is required. Java 21 is used for 1.21.11 and Java 25 for 26.x.

## New in 1.3.0

- Added a local-only mode using bundled, previously downloaded and user dictionaries. Online translation can be enabled separately for chat, NPCs, tooltips and world text. Google fallback requires an explicit opt-in.
- DeepL and Yandex have separate API keys. An existing key is migrated to the previously selected paid provider when possible. Test the selected provider from settings or with `/translator test`.
- Outgoing translation opens an editable draft. Review it and press **Send** to send it. Use `/translator draft` to reopen the current draft.
- Online cache entries expire after seven days and are keyed by language, channel and the service that produced the translation. Chat and NPC translations stay in memory by default.
- Added a local dictionary checker with match sources and regular-expression diagnostics. `/translator status` shows the active language and provider, dictionary state, pending translations and the latest error category.
- Language changes use the normal settings save action. Rebinding a hotkey preserves pending edits. Fixed a crash when opening the hotkey capture screen and a Minecraft 26.3 crash caused by the old saved unbound key.
- Preserve original chat click, hover and insertion actions. Apply translations after Minecraft inserts the original message.
- Limit network requests and response sizes, handle rate limits, and protect user dictionaries from partial writes. New profiles start with direct-message and outgoing translation disabled.
- Updated Gradle, Loom, Stonecutter and compatible Fabric dependencies. The release workflow validates all four JARs, declares the required Modrinth dependencies and synchronizes the project description after publication.

## Русский

- Локальный режим использует словари на компьютере. Для онлайн-перевода отдельно настраиваются чат, NPC, подсказки и текст игрового мира. Резервный Google включается отдельно.
- DeepL и Yandex используют раздельные ключи. Проверка выбранного ключа доступна в настройках и через `/translator test`.
- Исходящий перевод открывается как редактируемый черновик с кнопкой «Отправить». Повторно открыть его можно через `/translator draft`.
- Кэш учитывает провайдера и канал, записи действуют семь дней. Чат и диалоги NPC по умолчанию хранятся в памяти.
- Добавлены проверка пользовательского словаря и `/translator status`. Исправлены падения при назначении клавиш и входе в мир на 26.3 со старым профилем. Незавершённые настройки сохраняются при переназначении клавиш.

## Français

- Le mode local utilise les dictionnaires présents sur l’ordinateur. L’accès en ligne se règle par type de texte. Le secours Google peut être activé séparément.
- DeepL et Yandex ont chacun leur clé. Testez le service sélectionné dans les réglages ou avec `/translator test`.
- La traduction du chat sortant ouvre un brouillon modifiable. Validez avec **Envoyer** ou rouvrez le brouillon avec `/translator draft`.
- Le cache expire après sept jours et distingue le service et le canal. Le chat et les dialogues des PNJ restent en mémoire par défaut.
- Ajout d’un test du dictionnaire et de `/translator status`. Les réglages en attente sont conservés lors d’un changement de raccourci. Correction des plantages de l’écran de raccourci et des anciens profils sur Minecraft 26.3.
